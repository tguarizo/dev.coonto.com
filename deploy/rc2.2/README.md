# Publicação complementar RC2.2

Commit deve conter `[rc2-editorial] [rc2-final-audio] [sync-only]`.
A publicação compara o banco com a edição RC2.2 anterior antes de arquivar e publicar as novas edições ilustradas. Nenhum progresso ou nota é apagado.
A etapa final de áudio consulta créditos disponíveis e só gera arquivos faltantes. Falhas impedem sucesso do workflow; não usar --retry sem investigar tentativas anteriores.
A auditoria confere hash de texto/modelo/voz, arquivo MP3 com duração válida e registro publicado no banco. Isso não declara aprovação de pronúncia ou parecer humano.
